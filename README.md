# 宽带管家

> 双击一次连上校园宽带；开机自动连，不用再手动点。

一个小工具，专门解决「每次开机都要点好几下才能上网」这件事。

只依赖 Windows 自带组件（PowerShell 5.1、rasdial、WScript），**不需要管理员权限**，安装包 **166 KB**。

## 功能

| 功能 | 说明 |
|---|---|
| **双击即连** | 双击桌面图标，窗口打开的同时自动开始拨号 |
| **开机自动连** | 登录后静默把开了自启的宽带依次试一遍，连上就完事，不弹提示 |
| **多条宽带** | 可以加多条（宿舍、实验室、家里），自己排顺序，一条条试过去 |
| **全都连不上** | 自动弹出 Windows 的拨号窗口，让你手动来 |
| **开机极速启动** | 可选开关。打开后登录那一刻就开始拨号，比默认方式早十几秒 |
| **一键卸载** | 窗口里的按钮，图标 / 启动项 / 计划任务 / 程序文件一起清干净 |

## 使用

**第一次：**

1. 双击「宽带管家」
2. 点「添加宽带」，从列表里选一个系统里已有的宽带连接
3. 填一次宽带账号密码（运营商给的，**不是 WiFi 密码**）
4. 勾上「开机自动连接」
5. 点「立即连接」 → 通了

**以后：** 什么都不用做。开机它自己连。

## 安全性

- 宽带密码存在 `%LOCALAPPDATA%\SchoolBroadband\profiles.json`，用 Windows 自带的 **DPAPI** 加密
- 加密绑定「本机 + 当前 Windows 账户」，文件被拷走也解不开
- 程序不联网、不装服务、不驻留后台；拨号完成就退出
- 唯一的网络行为就是调用系统自带的 `rasdial` 去拨你配好的那条宽带

## 系统要求

- Windows 10 / 11
- 只支持 PPPoE 宽带（需要输账号密码的那种）
- 无需 .NET / Python / Node

## 装不上怎么办

**情况一：Windows 弹「已保护你的电脑」，或者浏览器直接拦下 exe**

程序没有购买数字签名证书（一年好几千块），所以 SmartScreen 会对它一视同仁地警告。

点「**更多信息**」→「**仍要运行**」即可。

**情况二：双击 exe 后红字报 `Setup failed: 找不到可写的解压目录`**

这是安全软件（火绒 / 360 / 电脑管家 / Windows Defender 的勒索软件防护）拦住了它往 `%TEMP%` 写文件，和这个软件本身有没有问题无关。

**不用改安全软件设置，改用备用包就行：**

1. 下载 Release 里的 `SchoolBroadband-Setup.zip`
2. 右键 →「**全部解压缩**」，得到一个 `SchoolBroadband-Setup` 文件夹
3. 进这个文件夹，双击 `install.bat`

zip 只是把文件原样解开，不写临时目录，不会被拦，装出来的东西完全一样。

**情况三：覆盖安装时红字报 `New-Item : Access to the path '…' is denied.`**

这是系统拒绝了往**安装目录**里写文件。先确认「宽带管家」窗口已经关掉——程序文件被占用时写不进去——然后再双击一次。

还不行就用上面的备用包。**已经装好的那套不受影响，不必卸载重装**：报错发生在覆盖的那一步，旧版本仍然完好。
